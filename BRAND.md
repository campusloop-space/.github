# CampusLoop — Brand & GitHub Metadata Guide

Single source of truth for how CampusLoop looks and describes itself on GitHub.
Keep every repo, profile and social preview consistent with this file.

## Logo

| Asset | File | Use |
|---|---|---|
| Mark (transparent) | `profile/assets/logo.png`, `profile/assets/logo.svg` | READMEs, docs, anywhere on light or dark backgrounds |
| Organization avatar | `profile/assets/avatar.png` | GitHub org profile picture — purple "C" on a deep-violet gradient, 1024×1024 |
| Avatar (light variant) | `profile/assets/avatar-white.png` | Light-background placements that need a solid tile |
| README banner | `profile/assets/banner.png` / `banner.svg` | Top of the org profile and repo READMEs, 1440×420 |
| Social preview | `profile/assets/social-preview.png` | Repo Settings → General → Social preview, 1280×640 |

The mark is the gradient "loop C" from [campusloop.space](https://campusloop.space) — don't redraw, recolor or stretch it.
